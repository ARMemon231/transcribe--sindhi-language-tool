# 📝 SindhiPaper AI

AI-powered OCR tool for digitizing Sindhi language exam papers and handwritten notes.

## ✨ Features

- 🎯 **High-Accuracy Sindhi OCR** - Recognizes 52 unique Sindhi characters
- 📄 **Smart Formatting** - Auto-structures question papers with headers and sections
- ✏️ **Manual Editing** - Fine-tune recognized text easily
- 📥 **PDF Export** - Save as professional A4 PDFs
- 🔤 **RTL Support** - Full Right-to-Left rendering with Lateef font

## 🚀 Quick Start

**Prerequisites:** Node.js and a [Gemini API key](https://ai.google.dev/)

```bash
# Clone and install
git clone https://github.com/yourusername/sindh-text-extractor.git
cd sindh-text-extractor
npm install

# Add your API key to .env.local
GEMINI_API_KEY=your_api_key_here

# Run the app
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 💻 Usage

1. Upload an image of a Sindhi question paper
2. Wait for AI processing
3. Review and edit the recognized text
4. Download as PDF
